# AI Systems Lab

This repository supports an AI Engineering course focused on building practical AI applications with Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

We use these foundations to implement AI agents: software systems that reason about the tasks they receive and can take actions to execute them, often autonomously.

## What We'll Learn

We'll build practical AI applications from day one. Throughout the course, we'll create:

- **FAQ Assistant** — answer questions from documentation
- **YouTube Podcast Summarizer** — process video content
- **Internal Documentation Assistant** — search company docs
- **Coding agents** — write and improve code
- **Deep research agents** — perform multi-step investigations
